# 专家

把常用的角色、方法与输出规范沉淀成「专家」，在对话中一键装填到输入框。

## 安装

在 Harness 打开 **插件 → 添加插件**，选择本目录（`plugins/dsh-experts`）的绝对路径，安装后启用。装好后左侧栏出现 **专家** 入口。

## 使用

- **应用**：点击卡片上的「应用」，提示词会载入当前会话的输入框。输入框为空时直接填入；已有草稿时追加到末尾，并保留原有内容。载入后自动切回对话页并把焦点放回输入框，不会自动发送。
- **撤销**：追加后 5 秒内可在顶部提示中点「撤销」，恢复应用前的草稿。
- **新建 / 编辑**：自定义名称、图标、分类、简介和提示词。新建的专家保存在本机，刷新或重启后仍在。
- **收藏与检索**：收藏的专家排在最前；支持按名称、场景或提示词内容搜索，也可按分类筛选。
- **没有会话时**：会自动新建会话并预填提示词；如果还没有工作区，会提示先在侧栏打开一个工作区。
- **输入框忙碌时**：正在发送消息时不会改写草稿，会提示稍后重试。

## 数据与备份

- 数据保存在浏览器本地存储 `@local/dsh-experts:v1`，与待办清单等插件互不影响。
- 「导出」生成 `dsh-experts-YYYY-MM-DD.json`；「导入」按专家 ID 合并，重复 ID 会跳过，格式错误会整体拒绝并提示原因。
- 「恢复内置专家」会把被修改或删除的内置专家还原为默认内容，收藏状态保留；你创建的专家不会被修改。存在已修改的内置专家时会先弹出确认，确认前可先导出备份。
- 需要清空重来时，可在读取失败的错误提示里点「重置专家库」。

## 兼容性

对照 DeepSeek Harness Desktop `0.2.2-rc.1`。插件注册以下扩展点：

- `sidebar.panellist`：侧栏「专家」入口
- `main`：专家库页面（面板 ID `local-experts`）
- `conversation.input.left`：无界面的输入框桥接，用于安全地写入当前草稿
- `shell.overlay`：顶部全局提示与「撤销」

界面跟随 Harness 的明暗主题，只使用主题 token 和 `light-dark()`，不依赖其它插件的 DOM 或样式。

## 开发与测试

根目录执行 `pnpm test` 会依次运行三个插件的冒烟测试；`pnpm test:experts` 只运行专家测试。专家测试使用 Playwright + React 真实组件，覆盖页面渲染、专家增删改、搜索筛选、收藏、应用/追加/撤销、无会话回退、输入框锁定、导入导出和内置恢复。

安装依赖（首次）：

```sh
pnpm install
```

使用本机 Edge 运行：

```powershell
$env:DSH_SMOKE_BROWSER_CHANNEL = 'msedge'
pnpm test
```
