# 航迹

> 等级只是配角，**纪录**和**画像**才是主角。

一个 Harness 插件：把「累计 token → 等级 → 徽章」的同质化玩法，换成「会破的个人最佳」和「可晒的航行人格」。

- **L1 轨道**：10 级，XP 由在场分钟、有效产出、轮次、工具广度四项组成，每项有日上限。
- **L2 航迹纪录**：8 条会破的个人最佳，破了弹一次「新纪录」。
- **L3 航行人格**：时段 / 节奏 / 协作 / 广度 4 轴，输出 4 个词 + 一个主称号。
- **L4 任务徽章**：12 枚一次性徽章。

入口在侧栏脚部（「设置」旁边）的小徽章 `Lv.6`，点击向上弹出面板，不跳转页面。

## 面板里的两个按钮

**重扫历史**（页脚左）——插件第一次启用时会在后台自动扫一遍本机会话日志（`sessionQuery.listSessions()` → `readSession(id)`），把安装前的会话折叠进账本。这个按钮就是再手动跑一次：

- 什么时候需要：插件停用了一段时间、或换了机器/清过账本之后，停用期间产生的会话不会被实时事件覆盖，只能靠扫描补回来。
- 为什么按了像没反应：扫描是**幂等**的，账本已经是最新时它会瞬间跑完、折叠 0 个事件。所以结果行会明确写成「已扫描 21 条会话 · 无新增」，有新数据时是「已扫描 22 条会话 · 新增 1 条」。
- 扫描过程中按钮变成「取消」，进度行显示「扫描中 12/21」。

**`?`**（等级右上角）——展开「这些数字怎么算的」：总 token 与账单的区别、有效产出、陪伴时长、在场时长、纪录口径。每个数字本身的悬停提示也在讲同一件事。

## 任务徽章图标

12 枚徽章内置了占位图形（`currentColor` 描边，未解锁自动灰度）。要换成自己的图标，把文件放进 [`medals/`](medals/)：

| 项 | 约定 |
|---|---|
| 目录 | `plugins/dsh-tracks/medals/` |
| 命名 | `<徽章id>.svg` / `.png` / `.webp` / `.jpg` |
| 尺寸 | 128 × 128（正方形、透明背景），显示 24 px |
| 留白 | 内容收在中间约 82%；外圈和底板由界面画，不要画进去 |
| 体积 | 单张 ≤ 40 KB |
| 生效 | Host 每 5 秒最多重扫一次，重新打开面板即可，不用重启 |

id 列表与详细约定见 [medals/README.md](medals/README.md)。图标走 `GET /api/plugins/tracks/medals/<id>.<ext>`，带 `ETag` 与 `max-age`，缺失或加载失败回落到内置占位图。

## 数据从哪来

| 来源 | 接口 | 用途 |
|---|---|---|
| 实时增量 | `session/event` | 日常累计（`assistant/message` 的 usage、`tool/call`、`user/message`、`turn/end`） |
| 一次性回填 | `sessionQuery.listSessions()` → `readSession(id)` → `readTitle(id)` | 装插件之前的历史会话 |
| 在场心跳 | Client `POST /api/plugins/tracks/tick` | 在场时长，关掉页面就停 |

去重规则：只折 `seq >= inheritedEventCount` 的事件。fork 会继承前缀，不切这一刀，分叉一次就会多算一遍。

账本落在 Host 侧：`<DSH_HOME>/plugin-data/dsh-tracks/ledger.json`（原子写入：先写 `.tmp` 再 `rename`）。localStorage 会被清理、多标签页会打架，所以客户端不存账本。

## 口径

面板里每个数字旁边都能点开「口径」，因为这三处最容易误读：

- **总 token ≠ 账单**：包含 cache 命中，1M 上下文聊几十轮就能到亿级。
- **有效产出** = `outputTokens`，这才是「写了多少东西」。
- **陪伴时长** = 有事件活动的时间聚类（相邻事件间隔 < 10 分钟累加），不是工时。
- **在场时长** = 页面可见 + 心跳，单次心跳上限 10 分钟，关掉页面就停。

## XP 与等级

`XP = 在场分钟×1 + output/2000 + turn×1 + 工具种类×2`，日上限分别是 240 / 200 / 60 / 40。
上限只压当日增量，不清零累计。

| Lv | 轨道 | 累计 XP |
|---|---|---:|
| 1 | 地面·整备 | 0 |
| 2 | 探空 | 60 |
| 3 | 近地轨道 | 240 |
| 4 | 空间站 | 700 |
| 5 | 同步轨道 | 1,600 |
| 6 | 地月转移 | 3,200 |
| 7 | 月面 | 6,000 |
| 8 | 火星转移 | 11,000 |
| 9 | 火星轨道 | 20,000 |
| 10 | 深空 | 36,000 |

满级后每 36,000 XP 加一颗 ★（最多显示 3 颗），不做无限等级通胀。

## 连续天数

有 `turn/end` 的连续自然日算连击。每连续 10 天存下一枚「补签」（最多 2 枚），断掉一天时自动消耗一枚，连击不清零。

## 时区

所有时间戳都是事件里的毫秒时间；切日、切小时都用本机系统时区。如果系统时区改了，账本会重建（旧的日/小时分桶无法换算），历史数据从会话日志重新回填。

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| `GET` | `/api/plugins/tracks/state` | 面板所需的全部数字 |
| `POST` | `/api/plugins/tracks/tick` | 在场心跳，`{ ms }` |
| `POST` | `/api/plugins/tracks/backfill` | `{ action: 'start' \| 'cancel' }` |
| `GET` | `/api/plugins/tracks/medals/<id>.<ext>` | 任务徽章图标（可缺省） |

没有工具、没有系统提示词、不写会话事件，所以对模型**零 token 成本**。

## 安装

```js
// 通过 plugin_manager 的 install_bundle，target 指向本目录
```

停用插件后入口消失，重新启用后账本照旧。删除 `<DSH_HOME>/plugin-data/dsh-tracks/` 可以从零开始。
