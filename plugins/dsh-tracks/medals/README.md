# 任务徽章图标

把自制图标放进这个目录，面板里的任务徽章会用它替换内置的占位图形。文件名就是徽章 id，扩展名决定服务端返回的 MIME 类型。

## 契约

| 项 | 约定 |
|---|---|
| 目录 | `plugins/dsh-tracks/medals/` |
| 命名 | `<徽章id>.svg` 或 `<徽章id>.png`（或 `.webp` / `.jpg`） |
| 尺寸 | **128 × 128**（正方形、透明背景），显示 24 px，2× 屏取 48 px，128 足够留出余量 |
| 留白 | 内容收在中间约 82%（四边各留 9% 安全边），圆形徽章不要顶到画布边缘 |
| 单张体积 | ≤ 40 KB（PNG 建议 8 色以内或压缩后 20 KB 左右） |
| 同名多格式 | 按 `.svg` → `.png` → `.webp` → `.jpg` 的顺序取第一个 |

**画法建议**：只画中间的图案，**不要自己画外圈和底板**。面板给每枚徽章一个 26 px 的圆形「插槽」：解锁时插槽有品牌色底板和描边，未解锁时是空心灰环——外圈和底板由界面负责，你的图只需要是透明底的图案（图形本身约占画布 70–82%）。如果画成带自身底色的满圆「硬币」，也能显示，但未解锁状态就只能靠整体灰度 + 30% 透明来区分，层次会弱一些。

## 生效方式

Host 每 5 秒最多重扫一次目录：放好文件后刷新面板（重新打开弹层）即可看到，不用重启应用。解锁状态由界面统一处理：解锁的徽章放在品牌色圆形底板上、满色显示；未解锁的只有灰色空心环 + 30% 透明的图案。缺失或加载失败的文件回落到内置占位图形。

## 为什么不用精灵图

只有 12 个图标，同源 HTTP 连接上几乎零成本；拆成单文件后可以「缺哪个补哪个」，每个文件独立缓存、独立替换，改一张不影响别的。精灵图需要维护坐标表和重新出图后的整体替换，反而更容易错位。
