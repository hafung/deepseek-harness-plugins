# 待办清单

适用于 DeepSeek Harness Desktop `0.2.0-rc.2` 的本地插件。

1. 在 Harness 打开 **插件 → 添加插件**。
2. 输入此目录的绝对路径，点击 **安装 → 立即启用**。
3. 从左侧点击 **待办清单**。页面支持添加、编辑、删除、完成、重新打开和筛选任务。

点击某条任务的 **发给主 Agent**，插件会在 **默认工作区** 新建一个会话并把任务名称和备注提交给主 Agent。待办清单保持打开，稍后可以从左侧默认工作区打开「待办：任务名称」会话查看进度和结果。

任务行显示执行状态。等待审批、计划审阅或回答时，点 **打开会话** 回到 Harness 处理。Agent 成功结束一轮后，任务显示 **待验收**，由你勾选完成。失败或中断也会单独标出。

发送结果待确认时，可以重试。重试沿用同一会话和首次提交的内容。

## JSON 备份与迁移

在筛选栏右侧点击 **导出 JSON**，保存整份待办清单。备份包含任务名称、备注、完成状态和派发记录。会话对话和附件由 Harness 单独保存。

点击 **导入 JSON**，选择备份文件。导入按任务 ID 合并，优先保留当前清单中的记录。当前 Harness 找得到的会话会重新关联。跨设备导入时，原会话缺失的任务可在本机重新派发。格式有误时，整份导入会停止并提示原因。

从旧版升级时，在插件页卸载旧版，然后用当前目录安装并启用 1.3.0。新版沿用原本的待办存档和会话关联。

待办保存在本机 Harness 的界面存储里。任务列表在重开应用后保留，清理应用数据会清除列表。通过插件页的开关可以停用此插件。
