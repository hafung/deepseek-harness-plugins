# 极光主题

把侧栏左上角的品牌文字和标志换成自己的，再给整个应用铺一层可选的光效背景——极光、夜樱、星夜、星穹、鎏金、青竹、墨笺、雾白，也可以直接用自己的图片。

## 安装

在 Harness 打开 **插件 → 添加插件**，选择本目录（`plugins/dsh-aurora`）的绝对路径，安装后启用。

插件会接管两件事：

- 侧栏品牌位（`sidebar.brand.mark` / `sidebar.brand.name`），并关闭随附的官方品牌包 `ui-brand-official`，保证品牌位只有一个占用者；
- `body` 上的全应用背景层，以及 `--dsw-alias-bg-base`、`--dsw-specific-sidebar-fill`、`--dsw-alias-bg-layer-1` 三个玻璃质感 token。

## 设置入口

**账号菜单 → 设置 → 皮肤**（左下角头像旁的菜单）。侧栏、顶栏都不放常驻按钮。

> 窗口最顶部的 **应用 / 编辑** 菜单是桌面端 Electron 主进程用原生菜单画的，插件系统没有向其中加项目的接口。设置类是插件配置的常规位置，所以放在这里；如果更希望放在侧栏的「更多」菜单里，改 `client.js` 末尾的一处注册即可。

## 可调项

标志和光效都排成一行：窗口放不下时**按住左右拖动**即可，不显示滚动条；普通点击（没有拖动）仍然是选中。

| 分组 | 项目 | 说明 |
| --- | --- | --- |
| 品牌 | 名称 | 最多 24 个字符；留空显示 `Aurora` |
| 品牌 | 标志 | 星芒 / 樱花 / 鸟居，或上传图片作为标志（会裁成圆角方形） |
| 背景 | 光效 | 极光 / 夜樱 / 星夜 / 星穹 / 鎏金 / 青竹 / 墨笺 / 雾白，明暗主题各有一套配色；青竹是低饱和绿色，墨笺是偏暖的护眼纸 + 墨绿，星穹是深空星带 |
| 背景 | 壁纸 | 上传本地图片（自动压缩到 2560 px 内，支持 32 MB 以内的文件），盖在光效之上；配合下面的压暗使用 |
| 背景 | 压暗 | 0–85%，只对壁纸生效，保证文字可读 |
| 背景 | 模糊 | 0–24 px，只模糊背景层，不影响界面 |

修改立即生效，不需要重启；设置保存在本机 `localStorage` 的 `@local/dsh-aurora:v1`。「恢复默认」回到初始的极光配色。

## 数据与卸载

- 只写 `localStorage`，不动会话、不碰其它插件的存储键。
- 上传的图片会先用 canvas 压到 2560 px（标志 256 px）再存成 WebP；仍然超过存储配额时会自动降一档重压，最终仍放不下时设置照常生效，但会提示这次没能保存。
- 卸载插件后：品牌恢复为官方标志，背景光效和玻璃 token 一并移除；本机保存的偏好留在 `localStorage`，重新安装后继续使用。

## 兼容性

对照 DeepSeek Harness Desktop `0.2.2-rc.1`。插件注册以下扩展点：

- `sidebar.brand.mark` / `sidebar.brand.name`：侧栏品牌
- `settings.section` / `settings.section.icon`：设置里的「皮肤」页与导航图标
- `theme.overrideTokens`：玻璃质感背景 token

样式只使用 `--dsw-*` 主题 token，亮色/暗色主题各自取色；不读取任何其它插件的 DOM 或样式。

## 已知限制

- **改动客户端后重新安装一次**：插件是浏览器端代码，改完 `client.js` 后在插件管理里移除再安装（或重启应用）才会加载新版本；已经装好的版本重启后自动生效。
- **官方品牌包被关闭**：本插件会在 bundle 补丁里关闭随附的 `ui-brand-official`。若客户端半部分加载失败，侧栏会退到 Harness 自带的兜底标志与版本标签，而不是官方鲸鱼标。
- **背景是装饰层**：它不改变任何功能按钮的可读性 token，但壁纸过亮时请配合「压暗」使用。
- **设置页跟随设置面板**：窄窗口下每行的标签与控件会改为上下排列。
- **入口只能在设置里**：桌面端顶部的「应用 / 编辑」菜单由 Electron 主进程的原生菜单实现，Cordis 插件没有注册接口；若要更浅的入口，可以把 `client.js` 末尾的 `settings.section` 换成侧栏 `sidebar.panellist.actions`（左下「更多」菜单里加一行）。
