# 热点 · Hotspot

DeepSeek Harness 的左侧栏资讯面板：从数百个精选 RSS 信源并发抓取，自动去重并按“信号价值”排出每日 Top 30，科技与 AI 优先，同时保留商业、科学、安全、全球与文化等题材。

## 功能

- **侧栏入口**：左侧栏「热点」图标，主面板展示今日榜单。
- **274 个精选信源**：来自 [Tidings RSS](https://github.com/fuxiaoai/tidings-rss)（CC0-1.0）的 Top 200、AI、新闻、科技媒体、研究、安全、社区、周刊、公司技术、微信公众号，另加 FT、WSJ、The Economist、Bloomberg Markets、Product Hunt 五个手工核验源。
- **Hacker News 与社区源**：收录 Hacker News 首页、Newest AI / Newest LLM、Show HN、Ask HN，以及 Lobsters、V2EX 等技术社区。
- **来源平衡**：优先公司/实验室一手来源和 Hacker News 发现的原站报道；中文媒体二手转述最多 8 条、同一家最多 2 条，中文内容整体上限 12 条，避免榜单被单一中文媒体占据。
- **每日与每小时扫描**：插件启动时自动检查更新；客户端保持打开期间每 60 分钟自动扫描。首次扫描会并发读取全部信源，之后使用 ETag / Last-Modified 条件请求降低带宽。
- **72 小时时效窗口**：Top 30 默认只从最近 72 小时的资讯中筛选；新鲜窗口不足 30 条时，最多回看到 120 小时补足，并标出「较早」。超过 120 小时的内容不会进入榜单，新闻不会永久占位。
- **价值排序**：时效性、信源质量、主题信号、摘要深度、跨源关注与题材多样性共同评分；配置了默认模型时，会再把 64 条候选交给模型精排，模型失败时自动回退到本地信号排序。AI 精排使用当前默认模型，每轮会消耗一次模型调用；页面会标记「AI 精排」或「本地信号」状态。
- **Top 30 卡片**：头条 + 网格卡片，按 AI 前沿、科技、商业、科学、安全、全球、文化分 Tab，可搜索标题、来源与关键词。
- **自媒体选题评分**：每条资讯额外显示 0–100 的选题适配度，用独立的细线指标呈现，并附具体选题角度；它衡量讨论度、共鸣入口、叙事空间与可视化潜力，与新闻本身的价值分开计算。标签按区间着色：85+ 金色、70–84 绿色、55–69 蓝色、55 以下灰色。
- **访问来源**：在新标签页打开原文。
- **收藏与看过**：卡片操作区的小星形按钮可收藏 / 取消收藏；「已知晓」会把文章归档到「看过」。两者都保存完整快照，不依赖当前 Top 30，因此旧榜单里的文章仍可在概览下方的「看过 / 收藏」入口回看。
- **网感转写**：仅对非中文原文显示。发给 Harness 智能体，要求保留原意与事实，不添油加醋，按简中互联网读者的阅读习惯重组成流畅、简洁、可直接发布的文章，而不是逐字翻译。
- **本地优先**：扫描在本机完成，缓存保存在 `$DSH_HOME/plugin-data/dsh-hotspot/cache.json`，不上传浏览记录。

## 安装

在 Harness 的 **插件 → 添加插件** 中选择本目录（包含 `package.json` 的 `plugins/dsh-hotspot`），安装并启用。插件会立即开始首次扫描；客户端刷新页面后可从左侧栏打开。

也可以在仓库中把本目录加入现有插件安装流程。安装后请保留此目录。

## 说明与边界

- RSS 与原文均来自第三方站点，可能超时、限流或只提供摘要；扫描失败不会清空上一轮可用榜单。
- 个别站点有反爬或付费墙，正文提取会退化为 RSS 摘要，并在发送给智能体的提示中说明，让 Harness 用 `web_fetch` 补全。
- “最有价值”是编辑信号与模型判断的组合，不是客观事实；每张卡片会展示入选理由和信号强度，方便快速复核。
- 自媒体选题评分也是参考维度，不代表平台流量承诺；它刻意与新闻价值分开，避免把“重要”误当成“适合做内容”。
- 本轮不收录视频与播客源，专注可阅读的文章类资讯。

## 开发

无构建步骤，Host 端为 Node ESM，Client 端是 Harness 的动态 Client 模块。

```text
plugins/dsh-hotspot/
├─ index.js          Host 插件入口与 HTTP 路由
├─ client.js         主面板与侧栏入口
├─ server/
│  ├─ rss.js         RSS / Atom / JSON Feed 抓取与解析
│  ├─ article.js     原文正文提取
│  ├─ rank.js        信号评分、模型精排、Top 30 选择
│  └─ hotspot.js     刷新编排、缓存、模型调用与查询
├─ sources.json      精选信源目录
└─ locale/           插件显示元数据
```
